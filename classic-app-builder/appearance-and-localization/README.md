# Appearance and localization

Applies to **Classic App Builder**. Screens and recordings in this section show the Classic interface.

Adjust the app's presentation while checking the impact on existing pages and users.

## Choose the scope

* [App theming](app-theming.md) for app-wide styling.
* [Global CSS and JavaScript](global-css-and-js.md) for customizations that may affect multiple pages.
* [Component Designer](../component-designer/) for custom component layout, states, and appearance.
* [Localization](localization/) for account and end-user language or timezone settings.
* [Application settings](application-settings.md) for related configuration.

## Review a visual change

Check text readability, empty and loading states, long labels, and supported screen sizes. Test interactive states such as hover, focus, and disabled controls where available.

A global CSS change may affect more than the page you are editing. Inspect representative pages after changing shared styling.

For localization, check the intended user's language and timezone separately from the builder's account preferences. Include dates, numbers, and labels in the review.
