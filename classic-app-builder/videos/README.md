Applies to **Classic App Builder**. Screens and recordings in this section show the Classic interface.

Use the existing Academy recordings alongside written guides. These recordings show Classic interfaces and may differ from the controls in your app.

## Use a recording effectively

Identify the intended result before following the clicks. Reproduce it with synthetic records, compare the result, and test a failure or empty case. If navigation differs, use the written reference for the feature rather than assuming a similarly named control has the same effect.

For current shared platform functionality, use [Authentication and SSO](../../access-and-sharing/authentication-and-sso/), [Environments](../../jet-bridge-deployment/environments/), and [Publish & Deploy](../../jet-bridge-deployment/overview.md).
