# Classic tutorials: internal tool and customer portal

These tutorials use the visual editor. Pick the one closest to the app you maintain or want to extend.

* [Quickstart](quickstart-2.md) introduces the Classic workflow.
* [Building an Internal Tool](quickstart/) connects data, builds UI, runs actions, and publishes.
* [Creating a Customer Portal](creating-a-customer-portal/) covers portal data, layout, and users.
* [Deep dives](part-2-intermediate/) add relations and advanced patterns.

Use test records when following a tutorial on an existing app. For a new prompt-built app, use [AI App Builder](https://app.gitbook.com/s/-LQ08RFAKZvFADEiXKFy/ai-app-builder).
