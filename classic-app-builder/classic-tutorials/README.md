## Use tutorials on an existing app

Work with an appropriate test environment and synthetic data. Before adapting a tutorial, identify the resource, record identifier, and role requirements in your own app.

After following the steps, verify the source result as well as the visible UI. For a customer portal, run [a two-customer isolation test](../../access-and-sharing/app-and-data-permissions/customer-data-isolation.md).

Recordings may show earlier Classic screens. The supporting references explain the concepts; verify the controls and outcomes in your app before release.
