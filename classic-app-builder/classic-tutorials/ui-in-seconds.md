# 🚀 Generate a record page or dashboard

Applies to **Classic App Builder**. Screens and recordings in this section show the Classic interface.

Use the Classic page-generation workflow to create a starting interface for a resource.

## Choose the intended outcome

| Interface     | Purpose                                            |
| ------------- | -------------------------------------------------- |
| Record Review | View the details of a record selected from a list. |
| Record Update | Edit the selected record.                          |
| Record Create | Add a record through a form.                       |
| Dashboard     | Present metrics and charts.                        |

## Build and check the page

1. Open the page-creation workflow in your Classic app.
2. Select the appropriate generated interface and intended resource.
3. Review the generated components and fields.
4. Inspect bindings, record identifiers, and any write operations.
5. Test with synthetic records before publishing.

For Record Update, select two different records and confirm that the correct one changes. For Record Create, verify the new record in the source. For a dashboard, check the aggregation and empty-state behavior.
