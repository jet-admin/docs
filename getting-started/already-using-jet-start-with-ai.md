# Already using Jet? Start with the AI builder

You can use the Prompt Assistant for a new app without rebuilding every Classic app. Start with a task that needs a new screen, process, or user flow, and decide which existing data and rules it depends on.

1. List the data sources, user roles, and actions the current app relies on.
2. Connect the same sources in a new AI app or use a test copy of the data. Name actual fields in the first prompt.
3. Build the smallest working slice and compare its screens, queries, and permissions with the existing app.
4. Test write actions and access with representative roles. Publish only after the new behavior is clear.

For a side-by-side choice, see [Choose AI or Classic App Builder](choose-ai-or-classic-app-builder.md). Keep the [Classic App Builder guides](https://app.gitbook.com/s/-LQ08RFAKZvFADEiXKFy/classic-app-builder) for maintaining your existing visual-builder app. Move from Classic to AI covers a gradual transition.
