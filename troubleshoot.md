# FAQ and Troubleshooting

Find the question or error that matches your situation. Start with the focused guide below, then contact support with the requested details if the problem continues.

## Billing and AI usage

* [AI credits: insufficient balance or usage limit](faq-and-troubleshooting/ai-credit-limit-errors.md) — check the affected allowance, paid-plan limits, and trial terms.
* [Cancel renewal, request a refund, or report an unexpected charge](faq-and-troubleshooting/cancellation-and-unexpected-charges.md) — verify renewal status and request review of a charge.
* [Find missing invoices and update billing details](faq-and-troubleshooting/missing-invoices-and-billing-details.md) — report missing invoice periods and request billing changes.
* [Affiliate terms and payouts](https://docs.jetadmin.io/affiliate-programs/program-terms-and-payouts) — check the program terms and the route for payout questions.

## Login and user access

* [Password-reset or invitation email not received](faq-and-troubleshooting/password-reset-and-invitation-emails.md) — check the sign-in method, delivery, and account state.
* [A user gets 403 or cannot access a page](faq-and-troubleshooting/403-and-user-permission-errors.md) — compare permissions and retest with a fresh sign-in.

For authentication setup, see [Authentication and SSO](https://docs.jetadmin.io/access-and-sharing/authentication-and-sso). If you need mandatory MFA or a single active device/session, confirm support for that requirement with your chosen authentication provider and Jet Admin before rollout.

## App configuration and backups

* [How to clone the whole app?](faq-and-troubleshooting/how-to-clone-the-whole-app.md)
* [Cross-Instance Backup & Restore](https://docs.jetadmin.io/jet-bridge-deployment/environments-releases-and-version-control/version-control/cross-instance-backup-and-restore)

Before shutting down an app, confirm which configuration, data, and files your export includes and how you will restore them. A backup or GitHub copy alone does not establish that an app can run independently of Jet Admin.

## Get help

Use the Jet Admin chat. If your team has a dedicated Slack channel, see [How to Connect to Slack Channel](faq-and-troubleshooting/how-to-connect-to-slack-channel.md).

Include the app URL, environment, exact error, time and timezone, steps to reproduce, and what you expected to happen. Mention when the task last worked and whether other users are affected. Add these details to an existing conversation about the same issue when possible.

Remove passwords, API keys, session tokens, payment security details, and unrelated customer data from screenshots and logs.
