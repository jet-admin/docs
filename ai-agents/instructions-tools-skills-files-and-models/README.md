# Instructions, tools, skills, files, and models

Define what an agent may do before giving it access to a system.

* [Agent Instructions](agent-instructions.md): the goal, boundaries, and expected output.
* [Agent Tools](agent-tools.md): the actions it can call; review credentials and write permissions.
* [Agent Skills](agent-skills.md): reusable capabilities for a task.
* [Agent Files](agent-files.md): context the agent may read.
* [AI Models](ai-models.md): choose a model available to your plan and deployment.

Start with a narrow task and the minimum necessary tools. Test the agent with records it should and should not access before connecting it to users or workflows.
