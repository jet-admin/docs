# Create your first agent

An agent uses instructions and tools to act on a task. Begin with one well-defined job, such as summarizing a ticket from a connected source. Keep write actions separate until you know how the agent behaves with test inputs.

1. Read [Agent basics](agents.md) and [Add an Agent](add-an-agent.md).
2. Write instructions that describe the goal, allowed sources, and when the agent should stop or ask for help.
3. Give it only the tools and files it needs. Check each tool’s access and credentials.
4. [Test the agent](../test-an-agent-safely.md) with safe records and both normal and unexpected requests.
5. Choose where to [run it](../run-agents-in-apps-workflows-and-tasks/), then monitor outcomes.

See [Instructions, tools, skills, files, and models](../instructions-tools-skills-files-and-models/) for setup details and [Agent templates](../agent-templates/) for reusable starting points.
