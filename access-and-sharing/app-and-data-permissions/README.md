# App and data permissions

A user’s ability to sign in does not by itself define what they can see or change. Set page, component, action, and data rules for the intended role, then test them with that role’s account.

[Granular Permissions](user-and-team-properties.md) covers detailed user and team properties. For customer portals, check that a user cannot reach another customer’s record through a list, detail view, filter, or action. For generated apps, also inspect the queries and tools behind each button. Follow [Govern AI-generated apps](../overview.md) before publishing.
