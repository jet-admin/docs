# Test and troubleshoot

Check both workflow execution and the resulting data before relying on the process.

1. [Test steps and complete workflows](test-steps-and-complete-workflows.md) explains test inputs, outputs, and error inspection.
2. [Troubleshoot common problems](troubleshoot-common-problems.md) maps symptoms to checks.
3. [Handle failures and prevent duplicate processing](../handle-outcomes/handle-failures-and-prevent-duplicate-processing.md) covers partial success and repeated events.

Start with fictional data. Testing an update, email, or other external action can perform that operation. Record the original state so you can recognize and clean up test changes.
