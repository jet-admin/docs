# Approvals and workflows with AI

Use an [approval workflow](task-approval.md) when a decision must happen before a record changes. Define who can approve, reject, and inspect the result.

[Workflows with AI](workflows-with-ai.md) can help draft steps from a description. Inspect generated triggers, conditions, credentials, and write actions before running the process. For tasks that require instructions and tools across several systems, consider [AI Agents](https://app.gitbook.com/s/-LQ08RFAKZvFADEiXKFy/ai-agents). Test both approval and rejection paths with safe records.
