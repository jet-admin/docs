# Build workflow steps

Configure what happens after the trigger, then connect each step to the data it needs.

1. [Add and configure actions](add-and-configure-actions/) to read or write data or perform an app action.
2. [Pass inputs into the workflow](pass-inputs-into-a-workflow.md).
3. [Use step outputs and return results](use-step-outputs-and-return-results.md).
4. [Add conditions and branches](add-conditions-and-branches.md).
5. [Process multiple records with iterators](process-multiple-records-with-iterators.md).
6. [Run parallel branches and add delays](run-parallel-branches-and-add-delays.md).

Use the [action reference](add-and-configure-actions/action-reference.md) to distinguish data operations, in-app actions, and app built-ins. If one operation needs another's output, make that dependency explicit in the workflow.
