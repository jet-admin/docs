# Workflows and AI

AI can help in two different stages of a workflow.

| Goal                                                           | Use                                                                                                           |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Describe the process and generate editable steps               | [Generate a workflow with AI](generate-a-workflow-with-ai.md)                                                 |
| Interpret input or make a contextual decision during execution | [Run an agent in a workflow](../../ai-agents/run-agents-in-apps-workflows-and-tasks/workflows-with-agents.md) |

Generated steps still need correct data sources, inputs, conditions, and credentials. An agent used during execution needs appropriate instructions and tools.

Test the complete process, including the data passed into and out of AI steps. Use [an approval process](../practical-guides/create-an-approval-process.md) when the business process requires a person to authorize an action.
