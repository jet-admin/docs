# Practical guides

Use these guides after you can build and test a simple workflow.

| Goal                                      | Guide                                                       | Result to check                                           |
| ----------------------------------------- | ----------------------------------------------------------- | --------------------------------------------------------- |
| Require a human decision before an action | [Create an approval process](create-an-approval-process.md) | Approval executes the intended action; rejection does not |
| Apply an action to an explicit selection  | [Process selected records](process-selected-records.md)     | Only selected record IDs are processed                    |
| Find eligible records on a schedule       | [Send scheduled reminders](send-scheduled-reminders.md)     | Only due, unprocessed records receive a reminder          |

Use fictional records and the actual field names in your source. [Build your first workflow](../build-your-first-workflow.md) explains the common button, parameter, and update setup.
