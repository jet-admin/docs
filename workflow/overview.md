# Workflows

Use a workflow when a business process follows defined steps. Choose the event that starts it, add actions and conditions, then test each path before letting it change live data.

Start with [Triggers](triggers.md), [Steps](steps/), and [Inputs, Outputs, Parameters](inputs-outputs-parameters.md). You can also [generate workflows with AI](workflows-with-ai.md). Review generated actions, credentials, and write operations before running them.

Other common patterns include [Scheduled Workflows](scheduled-workflows.md), [Webhooks](webhooks.md), and [Approval Workflow](task-approval.md). Use [Test & Debug](test-and-debug.md) before publishing.
