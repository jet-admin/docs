# Connect external automation tools

Use [Zapier](../../user-guide/data-sources/business-apps/zapier.md) when part of the process runs in a Zap. Connector access, setup, and the existing video are documented under **Data Sources → Business apps**.

To receive an HTTP event from an external service in Jet Admin, follow [Receive an incoming webhook](receive-an-incoming-webhook.md). Configure the sender to match the method and payload expected by your trigger.

For steps that run entirely inside Jet Admin, start with [Build your first workflow](../build-your-first-workflow.md).
