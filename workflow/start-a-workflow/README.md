# Start a workflow

Choose a trigger based on where the input comes from and when the work should run.

* [Choose a trigger](choose-a-trigger.md) compares component and background entry points.
* [Run from a button or list action](run-from-a-button-or-list-action.md) passes app values into a workflow.
* [Run on a schedule](run-on-a-schedule.md) starts recurring background work.
* [Receive an incoming webhook](receive-an-incoming-webhook.md) starts work from an external event.

Define the trigger's input before configuring write actions. A component's selected row is not an input to a background automation unless you explicitly supply the relevant identifier.
