# Select a page

Use the page selector above Preview to open the part of the app you want to inspect or change.

## Open a page

1. Open **Preview**.
2. Find the app address and current route above the preview.
3. Open the dropdown beside the route.
4. Select the page you want to inspect.
5. Confirm the route and the displayed page match your selection.

You can also use the app's own navigation to check the route a user would follow.

## Check the result

For a Tickets page, check its heading and records. Then open a second page and return to Tickets to confirm navigation works.

Selecting a page changes what you are looking at. When requesting an assistant change, also name the page explicitly:

> On the Tickets page, add a Priority filter. Keep the Dashboard page unchanged.

If the list is empty or the page is missing, confirm generation has finished and that the route exists. Inspect [Console and logs](../preview-and-troubleshoot/inspect-app-console-and-logs.md) if the page fails to load.
