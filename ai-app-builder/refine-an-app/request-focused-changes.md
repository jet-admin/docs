# Request focused changes

When a generated app is close to what you need, describe one observable change. Point to the page, component, field, or action, and say how you will check the result.

* “On the Orders page, add a filter for fulfillment status. Keep the customer detail page unchanged.”
* “On the approval form, require a reason when a manager rejects a request. Do not change the approval permissions.”
* “Show the ticket owner on the list page, using the Owner field from Tickets. Keep the existing sort order.”

After each revision, inspect the affected page and test its data action. If the change touches roles or records, try it with a representative test account. If the assistant makes a broader change than requested, identify the unexpected behavior and ask to correct that specific piece. For queries or transformations, see [Ask AI for queries and transformations](ask-ai.md).
