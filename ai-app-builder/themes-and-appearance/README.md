# Themes and appearance

Choose a design when creating an app, then use **Theme** above Preview to adjust its appearance.

## Choose a design before generation

{% hint style="info" %}
Design selection during app creation is part of the AI App Builder development preview.
{% endhint %}

1. Open the design picker alongside your app-creation prompt.
2. Choose a style from the available design cards, or use **Default**.
3. Describe the app, review the assistant's plan, and confirm generation.
4. Check the generated pages and controls in Preview.

![Design picker with available app styles](https://250870895-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F8xy7P3kSppSd57K7pcpL%2Fuploads%2FLGJ6G0sR1D3K0jFo7qXw%2Fsept29-designs.jpg?alt=media)

Your selected design is saved with the app and guides later assistant requests, helping new pages and edits follow the same style. The default Jet design also guides generated controls such as date pickers, sliders, and select menus.

![Generated Task Tracker using the default Jet design](https://250870895-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F8xy7P3kSppSd57K7pcpL%2Fuploads%2FbhqucOpQ00Pgn3ApMR41%2Fsept29-jet-theme.jpg?alt=media)

If an edit does not match the chosen design, identify the affected page or component and ask for a focused styling correction.

## Adjust the theme of an existing app

* Apply a theme template for a coordinated starting point.
* Customize theme settings for individual typography, color, border, and spacing choices.

Theme presets style the app. They are different from app templates that provide a starting app structure.

After changing the theme, check a list, a form, and a dialog in both light and dark modes where used. Also inspect Desktop, Tablet, and Mobile previews.
