# Themes and appearance

Use **Theme** above Preview to control the app's visual style.

* [Apply a theme template](apply-a-theme-template.md) for a coordinated starting point.
* [Customize theme settings](customize-theme-settings.md) for individual typography, color, border, and spacing choices.

Theme presets style the app. They are different from app templates that provide a starting app structure.

After changing the theme, check a list, a form, and a dialog in both light and dark modes where used. Also inspect [Desktop, Tablet, and Mobile previews](../preview-and-troubleshoot/control-app-preview.md).
