# Write a useful prompt

Give Prompt Assistant enough context to build the first working version of your app. Name the users, the connected data, the screens they need, and the actions they can take.

A useful first prompt says:

> Build an order operations app for support staff. Use the Orders and Customers tables. Show open orders in a filterable table, a detail screen with customer and payment information, and an action to update fulfillment status. Keep refund actions available only to managers.

Start with one workflow. Specify the real table and field names where possible. After generation, compare the result with your data and access rules. Ask for targeted revisions such as “Add a status filter to the Orders table” or “Show a warning before changing fulfillment status.”
