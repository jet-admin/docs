# Preview and troubleshoot

Use Preview to inspect how the app looks and behaves before publishing.

| Task                                                                   | Guide                                                                 |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Open a particular route                                                | [Select a page](../refine-an-app/select-a-page.md)                    |
| Check Desktop, Tablet, and Mobile; expand full screen; stop or restart | [Control app Preview](control-app-preview.md)                         |
| Check an invited user's experience                                     | [Preview as an invited user](preview-as-an-invited-user.md)           |
| Investigate errors and unexpected behavior                             | [Inspect App Console and logs](inspect-app-console-and-logs.md)       |
| Resolve problems with generation or changes                            | [Troubleshoot the AI Assistant](troubleshoot-the-prompt-assistant.md) |

Preview can run actions against connected systems. Use test records for checks that create or modify data.

When the app behaves as intended, continue with [Test and publish](../test-and-publish/).
