# Troubleshoot the Prompt Assistant

If generation does not produce the expected app, isolate the failing step before requesting another broad change.

* **Missing data or fields:** check the source connection, available tables, credential scope, and the exact field names in the prompt.
* **Wrong pages or actions:** request a focused revision that names the affected screen and expected behavior. Compare the result with the original task.
* **An action fails:** inspect the query or API request, required parameters, and data-source permissions. Try a safe test record.
* **A user sees the wrong records:** inspect authentication, roles, and record-level filters. Test with a separate account.
* **Usage is unavailable or limited:** review [credits and rate limits](../../account/credits-and-rate-limits/how-credits-work.md) under Account.

Keep the prompt and a reproducible test case when asking support for help. For source-specific failures, see [FAQ and Troubleshooting](../../troubleshoot.md).
