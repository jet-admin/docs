# Test and publish

Release an app only after its data, actions, and access match the intended use.

1. [Review the generated pages and logic](../refine-an-app/review-and-refine.md).
2. [Check the supported screen sizes](../preview-and-troubleshoot/control-app-preview.md).
3. [Test data actions and user access](check-data-actions-and-user-access.md) using safe records.
4. [Preview as an invited test user](../preview-and-troubleshoot/preview-as-an-invited-user.md).
5. [Publish and repeat the critical checks](preview-and-publish-an-ai-app.md) in the published app.

If a check fails, capture the actual result and [relevant logs](../preview-and-troubleshoot/inspect-app-console-and-logs.md), request a focused correction, and test again.

For custom domains, environments, and deployment options, see [Publish & Deploy](https://app.gitbook.com/s/-LQ08RFAKZvFADEiXKFy/jet-bridge-deployment).

## Review or revert app changes

Open [Version History](version-history.md) to inspect recorded changes, preview an earlier version, or use **Revert version**. Repeat the affected data and access tests before publishing the resulting app.
