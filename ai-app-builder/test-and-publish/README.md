# Test and publish

Before sharing an AI-generated app, check the records it reads, the actions it can run, and the people who can use it.

1. Check data actions and user access with safe records and representative roles.
2. Preview and publish an AI app when the result matches the intended task.
3. Troubleshoot the Prompt Assistant if generation or revisions fail.

Deployment choices, environments, and domains are documented in [Publish & Deploy](https://app.gitbook.com/s/-LQ08RFAKZvFADEiXKFy/jet-bridge-deployment).
