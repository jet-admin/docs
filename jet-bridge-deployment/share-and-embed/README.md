# Share and embed

Choose how people will reach your published app, then verify their access.

| Task                                                               | Where to start                                              |
| ------------------------------------------------------------------ | ----------------------------------------------------------- |
| Invite a named person or a selected team audience                  | [Share with the intended audience](share-your-app.md)       |
| Display the app inside another site or tool                        | [Embed an app](embed-an-app.md)                             |
| Set the title, description, and image used when sharing an address | [Set the social sharing preview](social-sharing-preview.md) |
| Give the app a custom address                                      | [Custom domains](../custom-domains/)                        |

## Two different sharing controls

The top-toolbar **Share** button opens membership invitations. **More → Sharing** contains social preview metadata. Editing a social title or image does not grant membership or change the access policy.

Before sharing, [verify the published release](../publish-your-app/verify-a-release.md) with the intended account. Use [Authentication and SSO](../../access-and-sharing/authentication-and-sso/) and [App and data permissions](../../access-and-sharing/app-and-data-permissions/) for access configuration.

A published URL, an invitation link, and an embed link can have different purposes. Confirm the behavior of the actual link you distribute.
