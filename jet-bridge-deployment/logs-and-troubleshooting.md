# Logs and troubleshooting

When a published app fails, identify whether the problem is the app, a data source, authentication, or the deployment service.

1. Record the page, action, user role, environment, and time of the failure.
2. Check app [Logs](../access-and-sharing/audit-logs-privacy-and-security/logs.md) and relevant [Audit logs](../access-and-sharing/audit-logs-privacy-and-security/audit-logs.md).
3. Test the data connection and credential scope with a safe request.
4. For Jet Bridge, inspect [Common Problems](cloud-jet-bridge-and-on-premises/jet-admin/common-problems.md). For on-premises setup, inspect the [Service Health Check](cloud-jet-bridge-and-on-premises/on-premise/service-health-check.md) and its Common Problems guide.
5. Compare the last working release with the current [environment and version](environments-releases-and-version-control/version-control/).

For prompt generation issues, see [Troubleshoot the Prompt Assistant](../ai-app-builder/test-and-publish/).
