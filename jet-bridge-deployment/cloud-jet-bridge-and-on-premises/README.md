# Cloud, Jet Bridge, and on-premises deployment

Choose the deployment model that matches where the app and its data must run. [Cloud](cloud.md), [Self-hosted Jet Bridge](jet-admin/), and [On-premise](on-premise/) have separate setup guides.

Confirm network access to each data source, credential handling, and the user authentication path in the chosen model. Test the app in its target environment before opening it to users. For setup failures, use the Common Problems and health-check guides under the deployment model, then Logs and troubleshooting. Current plan availability is listed on the [Jet Admin pricing page](https://www.jetadmin.io/pricing).
