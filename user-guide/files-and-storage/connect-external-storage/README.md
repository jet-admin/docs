# Connect external storage

Connect a storage provider to work with its files and folders in Jet Admin. Before connecting, check that your credentials can access the storage and perform the operations your app needs.

Choose your provider:

* [Amazon S3 and S3-compatible storage](amazon-s3.md)
* [Google Cloud Storage](google-cloud-storage.md)
* [Supabase Storage](supabase-storage.md)
* [Firebase Cloud Storage](firebase-cloud-storage.md)

Follow the provider guide to complete setup. Then open the connected storage in the Data Editor and check that you can access the expected files.

For a resource that needs custom storage queries, see [Configure resource storage and app uploads](../configure-resource-storage.md). To work with a connected storage, see [Upload and manage files](../upload-and-manage-files.md).
