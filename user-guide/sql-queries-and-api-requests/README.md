# SQL queries and API requests

Use a query or request when a connected data source needs a custom read or action. Inspect the method, parameters, credentials, and expected result before attaching it to an app screen or workflow.

* [SQL Query Builder](sql-query-builder.md) and [Making SQL queries](make-a-sql-query.md) cover database queries.
* [API Builder](api-builder/) and [Making API requests](make-an-http-request.md) cover HTTP requests.
* [Text to SQL](text-to-sql.md) and [Ask AI for queries and transformations](../../ai-app-builder/refine-an-app/ask-ai.md) offer assistance, but generated requests still need review.

Use a safe dataset to test write requests. The connector guide is under [Data Sources](../data-sources/).
