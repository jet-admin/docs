# Jet Databases

Jet Databases provides a PostgreSQL database hosted by Jet Admin. In the resource picker, it is called **Jet Tables**.

## Create your first table

1. Open **Data** in your application.
2. Open the resource menu and select **Add Resource**.
3. Choose **New Data — using Jet Tables**.
4. Choose **New Table**, a **Template**, or **Import from File**.

Follow [Create a table](create-a-table.md) for the full setup, or [Import and export data](import-and-export-data.md) to start from a file.
