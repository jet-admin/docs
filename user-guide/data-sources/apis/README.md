# APIs

Use an API connection when data or actions are exposed by an HTTP, GraphQL, or MCP endpoint. Identify the base URL, authentication method, required parameters, and any limits set by the service.

Begin with [REST API](rest-api/), [GraphQL](graphql.md), or the connector guide for your service. Test a read before adding a write action. For requests created with AI, review the endpoint, method, and credentials in [API Builder](../../sql-queries-and-api-requests/api-builder/).
