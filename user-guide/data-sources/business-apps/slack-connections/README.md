# Slack

Choose how to connect Slack to Jet Admin.

| Connection method               | Use it for                                                                       |
| ------------------------------- | -------------------------------------------------------------------------------- |
| [OAuth](../slack-1.md)          | Access workspace collections and actions through an authorized Slack connection. |
| [Incoming webhook](../slack.md) | Send notifications to the channel associated with a webhook.                     |

Follow the guide for the connection method you need. An incoming webhook does not provide the workspace collections available through the OAuth connection.
