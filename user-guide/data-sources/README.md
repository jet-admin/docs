# Data Sources

Connect the systems your app already uses. Jet Admin supports [200+ integrations](https://www.jetadmin.io/integrations), including databases, APIs, business apps, and AI services. Choose the source that owns your records, connect it, and confirm the fields and actions you will use in your app.

## Start with your source

* [Database resources](databases/sql-databases/), including [MySQL](databases/mysql.md)
* [REST API](apis/rest-api/) and [GraphQL](apis/graphql.md)
* [Airtable](databases/airtable.md), [Salesforce](databases/salesforce.md), [HubSpot](databases/hubspot.md), and [Stripe](databases/stripe.md)
* [Firebase / Firestore](databases/firebase-firestore/) and [Google Sheets](databases/google-sheets.md)

If you need a new table inside Jet Admin, start with [Jet Databases](../jet-databases/). To keep a copy of source data refreshed, see [Synced tables](../synced-tables/). After connecting data, [create an app with AI](../../ai-app-builder/create-an-app/).
