## Check what the connection supports

Before building a screen or automation, confirm authentication, available collections, supported read/write actions, and whether **Direct** or **Sync** is offered. Capabilities vary by connector and account.

Use [Jet Databases](../jet-databases/) for new app data. For refresh behavior and combining source data, see [Synced tables](../synced-tables/).
