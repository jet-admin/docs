# Databases

Connect a database when the source already owns your app’s records. Check connection credentials, schema access, and read or write permissions before creating an app.

Start with [Database resources](sql-databases/), or open a specific connector such as [MySQL](mysql.md), [MongoDB](mongodb.md), [Snowflake](snowflake.md), or [Supabase](supabase.md). For custom queries, see SQL queries and API requests.
