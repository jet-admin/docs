# Storage and files

Choose a storage connector for files the app must upload, retrieve, or reference. Match the credential and storage permissions to the users who need access.

Guides include [Amazon S3](amazon-s3.md), [Google Cloud Storage](google-cloud-storage.md), [Supabase Storage](supabase-storage.md), and [File Storage and Uploading](../../data/file-storage.md). For tables and files stored inside Jet Admin, see [Jet Databases](../../jet-databases/).
