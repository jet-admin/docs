# Fields

Choose a field type, configure how it appears, or calculate a value.

* [Field types](field-types.md): choose how values are represented.
* [Add and configure fields](add-and-configure-fields.md): create fields in Jet Databases and configure display.
* [AI fields](ai-fields.md): configure AI-assisted field values.
* [Computed fields](../computed-fields/): formulas, lookups, rollups, and JavaScript.

For an external source, distinguish changing a field's display in Jet Admin from changing the source schema. After adding source tables or fields, use [Sync schema changes](../../synced-tables/syncing-schema-and-data.md).
