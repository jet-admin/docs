# Manage app data

Use the Data Editor to inspect and manage records from your connected resources. Available editing actions depend on the resource and its permissions.

Start with [Navigate the Data Editor](new-ui-and-ux.md) to select a resource, open a collection, and arrange the grid.

| What you want to do                | Start here                                                           |
| ---------------------------------- | -------------------------------------------------------------------- |
| Find, add, or edit records         | [Records](records/)                                                  |
| Choose types and configure columns | [Fields](fields/)                                                    |
| Link records across tables         | [Relationships](relationships/)                                      |
| Calculate or derive values         | [Computed fields](computed-fields/)                                  |
| Import or export a file            | [Import and export data](../jet-databases/import-and-export-data.md) |
| Refresh source tables or fields    | [Sync schema changes](../synced-tables/syncing-schema-and-data.md)   |
| Upload attachments                 | [Upload and manage files](file-storage.md)                           |

## Before editing

Identify the source of truth and confirm that your account can perform the intended action. After a test edit, reopen the record and check the saved value. For connected services, also check the original source when the connector supports writes.

Hiding a field or filtering a table changes the view; it does not establish access permissions.
