# Credits & Rate Limits

AI credits measure AI building usage; rate limits control how quickly a request can be made. They are different constraints.

* [How credits work](how-credits-work.md) explains which AI Builder activity uses credits.
* [AI credit limits](ai-credit-limits.md) covers the monthly plan allowance.
* [Rate Limits](rate-limits.md) covers request throughput.

The [Jet Admin pricing page](https://www.jetadmin.io/pricing) says AI credits are spent when the AI Builder generates an app from a prompt or makes substantial edits, while people simply using a built app do not spend building credits. It does not publish one fixed credit cost per prompt or a numerical API rate-limit schedule. Check your account’s billing and usage view, and confirm endpoint-specific limits with support before a high-volume integration.
